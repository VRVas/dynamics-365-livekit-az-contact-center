# Voice integration

Use [channel integration](../../docs/channel-integration.md) for shared API and
optional agent-assist boundaries, and the
[native runbook](../../docs/dynamics-native-voice/README.md) for Dynamics voice.

Native conversations are not mirrored into the custom Assist transcript stream.
The source template contains no deployed service URLs or reusable credentials.
See the [voice service README](README.md) for endpoints and settings.
